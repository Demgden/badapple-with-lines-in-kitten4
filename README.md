## 转换器

下载main.cpp并解压后用C++17以下版本编译（或直接下载converter v1.0.0 main.exe，默认2次高斯2.5pix抽稀）

可调节参数：读取帧率，处理帧数(默认全部)，输出分辨率(对应坐标)，二值化阈值，高斯模糊，抽稀容差。

将main.exe放置在读取视频文件同级并运行，生成x.txt、y.txt、帧索引.txt，复制到kitten4播放器对应名称列表即可播放。
